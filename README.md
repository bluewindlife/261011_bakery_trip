## v1.0.0

下田流を最優先に、未実施だった9/22の東京案から和甘とComme’N本店を維持。日曜通常休のmaru bagelは外し、奥沢から近いKepo自由が丘店を任意の代替にした。05:00出発、14:00ごろ帰路へ、17:30–19:30帰宅を目標にする。

- 和甘の10月商品は公式予約ページの「南瓜マスカルポーネ」。受取期間10/1〜10/31、¥670、1注文3個まで。
- 予約受付は7日前〜2日前。10/11分は10/4〜10/9。10/5の画面ではカレンダー全日×で、10/11の予約枠は未確認・未確保。原因や売切れを推測しない。
- 下田流は日曜の通常営業情報あり。10/11個別告知は未確認。公式Instagramの取得ができなかったので直前確認を必須とした。
- Kepo自由が丘店は運営会社の現行店舗情報に掲載。営業時間10:00–19:00、日曜は通常営業。ブランドメニューと支店での取扱い・在庫を分けて表示。
- 東名の工事規制・10/10〜12の休日割引対象外を反映。移動時間は計画枠であり、リアルタイム経路検索の値ではない。
- 予約不可時の大宮省略、下田流が使えない時のHIGU代替、遅れた時のKepo省略を掲載。
- 端末内チェック保存、JSTの当日予定表示、外部画像失敗時の除去、印刷用表示。

調査基準日：2026-10-05（日本時間）。出典と未確認事項はページ末尾に掲載。予約、注文、店舗への連絡は実行していない。

## 公開・確認

GitHub Pagesはmainブランチのルートを公開元に設定する。静的HTML/CSS/JavaScriptだけで動作し、ビルドや秘密情報は不要。

ローカル確認：`python -m http.server 8765 --directory outputs/261011_bakery_trip`（作業フォルダから）。リポジトリ内では `python -m http.server 8765`。

`node --check script.js` と `node scripts/verify-source.mjs` で静的検査を実行。GitHub Actionsでも同じ検査を実行する。
