## v1.1.0 — 駐車場を追記（2026-10-06）

各訪問先とHIGUの代替用に、合計8か所の候補を掲載。往復徒歩・買い物を含めた駐車時間で計算し、1店舗約1,000円以内、店舗まで片道徒歩5分以内を目安に選定した。料金・住所・台数・車両制限・Google Maps徒歩経路・公式満空リンクをカードにまとめた。

本命3店を60分ずつ利用すると合計1,500円。洗足で40分追加すると合計1,940円。JACKにはリアルタイムの平面区画の満空リンクを確認できず、現地確認とした。ほかはタイムズ公式の満空ページへリンクする。満空をサイト内に固定表示しない。

WRX S4向けに全幅1.9m以上の受入条件を優先。JACKの機械式、最低地上高150mm以上が条件のNPC24H高島平7丁目、徒歩条件を超える候補は除外。年式・装備は未確認のため実車と現地の車両制限を優先する。

Kepo自由が丘店には2025年12月10日の閉店情報があるため、任意の訪問先を洗足店に修正した。運営会社の一覧には自由が丘店の情報が残っているが、閉店報道・Google Maps・食べログと相違がある。洗足店の閉店時刻も運営会社19時と外部店舗情報17時の相違を明記。10/11の自由が丘女神まつりの交通規制も追記した。

## 公開・確認

GitHub Pagesはmainブランチのルートを公開元に設定する。静的HTML/CSS/JavaScriptだけで動作し、ビルドや秘密情報は不要。

ローカル確認：`python -m http.server 8765 --directory outputs/261011_bakery_trip`（作業フォルダから）。リポジトリ内では `python -m http.server 8765`。

`node --check script.js` と `node scripts/verify-source.mjs` で静的検査を実行。GitHub Actionsでも同じ検査を実行する。
