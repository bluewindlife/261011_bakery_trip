## v1.4.0 — 比較候補を整理・ZONO12時受取を反映（2026-10-10）

ZONOはご本人から「12時前後訪問・取り置き済み」と確認。旅程は下田流08:30、タヌキ10:00、ZONO12:00前後、Comme’N13:20–13:50、帰路14:00ごろ。早着分は休憩・遅れの吸収に使う。ZONOを12時到着できなければ自動で省く旧判断は削除し、店の受取条件に従う。

比較欄から採用済みのタヌキ・ZONOを削除し、写真付きの和甘を移動。候補は和甘・Kepo・HIGU・TSUBASA・Ryumon・KEN・MARUICHIの7店。カードにおすすめ時刻と入替対象を記載。和甘10:10–10:40、MARUICHI10:00–10:30、TSUBASA10:00–10:45はタヌキの入替。HIGU・KEN09:00–09:40は下田流の入替。Kepo13:20–13:50はComme’Nの入替。Ryumonは別日09:00–10:00を提案。時刻は動線上の計画枠で、当日の交通や在庫の保証ではない。

和甘のJACK大宮・平面区画を入替時のみの候補Pとして復元（徒歩5分・60分400円）。10/10に公式で料金・32台・寸法を再確認。和甘10月南瓜670円、予約は受取2日前23:59締切のため10/11分は締切経過。未予約で採用するなら店頭在庫次第。通常営業時間を再確認した店と、10/6時点のKENは区別して表示。

ZONOの準備チェックは「取り置き返信・受取情報を保存」に変更し、新しいキーを使う。取り置きの事実はバッジにも常時表示し、未成立の扱いは削除。こちらから新たな予約・注文・連絡は行っていない。
