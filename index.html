板橋区高島平7-26-4 / 通常 7:30〜売切れ / 専用Pなし

  • 8時台到着目標。7:30の開店待ちのための早出はしない
  • あんバターが無くても生地中心に選ぶ。現金を用意

世田谷区奥沢7-18-5 / 7:00–18:00 / 公式は年中無休

Kepobagels 自由が丘店

目黒区自由が丘1-28-8 自由が丘デパート1F / 10:00–19:00

日曜通常休のmaruに代えて、元の比較候補Kepoへ。運営会社の現行案内には自由が丘店があり、奥沢から近い。パン3店で十分なら省略し、足すならここ1店まで。

生地を比べる小さな買い方

  • プレーン酵母6% — ブランド公式では噛みごたえ・中のもちを重視
  • プレーン酵母10% — ブランド公式ではより柔らかい方向
  • 甘い系を1つ — ごまさつ・粒あんクリームチーズ等、支店店頭にあるものから
  • 6% / 10%は自由が丘店の取扱い・当日製造を未確認。無ければ店頭のプレーンで比較

採用する条件

  • 定休日は第2・第4火曜と毎週水曜。日曜は通常営業に一致
  • 10/11の臨時変更と商品・取り置き条件は支店で確認
  • 13時台前半に買い終え、14時ごろ帰路へ入れる見込みがある
  • Comme’N後は徒歩または車で移動。徒歩圏だが駐車時間・追加料金を確認
  • 洗足店は8:00–19:00。自由が丘店が使えない時だけ代替を検討

遅れ・買いすぎ・疲れが出たら

最初にKepoを省く。予約した和甘は受取条件を優先し、変更が必要なら店舗の案内に従う。購入済みパンで昼食を済ませ、余白を休憩へ回す。

13:30で追加店を打ち切り、14時ごろ帰路へ。帰宅ナビが19:30を越えても、休憩を削って取り戻さない。
